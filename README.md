
# FastAPI E-commerce API

Demo‑backend интернет‑магазина на Python + FastAPI. Проект создан для демонстрации принципов построения REST API, работы с базами данных и реализации бизнес‑логики в веб‑приложениях.

## О проекте

Это учебный бэкенд для интернет‑магазина с полной реализацией CRUD‑операций и бизнес‑логикой. Проект демонстрирует:
* чёткое разделение на слои (роутеры → сервисы → репозитории → модели/схемы);
* асинхронную работу с БД;
* аутентификацию и авторизацию с ролями пользователей;
* ведение логов;
* контейнеризацию.

## Ключевые функции

* **Управление пользователями**: регистрация, вход в систему, обновление профиля.
* **Роли пользователей**: покупатель, продавец, администратор.
* **Управление товарами**: добавление, редактирование, удаление, категории.
* **Корзина покупок**: добавление товаров, изменение количества, удаление.
* **Заказы**: оформление, просмотр истории, отслеживание статуса.
* **Отзывы**: пользователи могут оставлять отзывы и оценки к купленным товарам.
* **Аутентификация**: JWT‑токены (access и refresh).
* **Валидация данных**: Pydantic.
* **Логирование**: loguru + middleware для логирования запросов.

## Стек технологий

| Слой / задача | Технологии / подход |
|--------------|-------------------|
| Web‑framework / API | FastAPI |
| База данных | PostgreSQL + SQLAlchemy + asyncpg |
| Миграции | Alembic |
| Логирование | loguru + middleware |
| Авторизация / Аутентификация | JWT (access / refresh), роли (buyer / seller / admin) |
| Контейнеризация / DevOps | Docker, docker‑compose |
| Валидация / Схемы | Pydantic |
| REST API / CRUD | Сервисы → репозитории |
| Работа с запросами | Async / await, асинхронные сессии БД |

## Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Godzilka213/fastapi_ecommerce.git
   cd fastapi_ecommerce
Скопируйте пример окружения:

bash
cp .env.example .env
Заполните обязательные поля в .env:

DATABASE_URL - ссылка на вашу БД

SECRET_KEY — секретный ключ для JWT (сгенерировать);

Запустите проект через Docker Compose:

bash
docker compose up --build
Проект использует Alembic для миграций. При запуске автоматически:

создаются все таблицы в БД;

создаётся администратор с данными из .env.

После запуска API доступно по адресу: http://localhost:8000

Для остановки проекта выполните:

bash
docker compose down
